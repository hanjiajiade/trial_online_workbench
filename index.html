部署说明

  1. 将此仓库关联到 GitHub 后，在仓库 Settings → Pages 中选择部署来源。
  2. 若使用 GitHub Actions，可参考 .github/workflows/pages.yml 自动发布到 gh-pages 分支。
  3. 若使用 直接部署，可将 Pages 来源设为当前分支根目录，入口文件为 index.html。
  4. 所有页面均为静态 HTML，可直接在浏览器打开，无需构建。
